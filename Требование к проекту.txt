Разработать многостраничный сайт, по выбранному макету. Макет может быть подобран в любом удобном формате (фигма, psd, изображение, собственный макет). Количество страниц не менее трех. Темы для проекта могут быть выбраны студентом, в рамках цензуры допустимой для учебного заведения.
 
1) Сайт должен иметь полноценный адаптив (телефон, средний экран, широкий экран)
2) Сайт должен иметь исчерпывающее количество контента.
3) Контен сайта должен быть разнообразным и графически лаконичным.
4) Контент должен иметь анимацию и иметь относительную интерактивность
5) Файловая структура сайта должна быть понятная и грамотная
6) Иерархическая структура кода должна быть правильно подобрана
7) Идентификаторы должны быть осмысленными
8) Ключевые сегменты кода должны быть сопровождены комментариями
9) При сборке макета должны быть применены семантические теги.
10) Ссылки и пути должны быть прокинуты правильно и отрабатывать при различных способах запуска сайта
11) Селекторы должны быть подобраны грамотно и распределены с учетом удобства и минимизации
12) Сайт должен быть выгружен на хостинг
13) Код сайта должен быть валидным при проверке по W3C
